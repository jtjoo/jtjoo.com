# Jintae Joo - Personal Portfolio Website

This is a clean, modern, and fully responsive static website for Jintae Joo's professional portfolio. It is built with plain HTML and CSS, requires no backend, and is easy to deploy and maintain.

## Features

- **Simple & Clean:** A single-page design that focuses on content.
- **Fully Responsive:** Looks great on desktops, tablets, and mobile phones.
- **Dark / Light Mode:** Includes a theme toggle that respects and saves the user's preference (using system preference as a default).
- **Static Site:** No database or server-side language required. Can be hosted on any static web host.
- **Inline SVGs:** All social media icons are embedded in the HTML for fast loading and easy color changes.

## Files

This project consists of three main files:

- `index.html`: The main file containing all HTML content and the dark mode script.
- `style.css`: The stylesheet containing all layout, color, and responsiveness rules.
- `profile.jpg`: The profile image. (You must provide this file yourself).
